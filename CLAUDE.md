# AI Assistant Guidelines

Use these conventions when working on this project.

## Language

- Use **JavaScript** when code is needed.

## Commits

- Follow [Conventional Commits](https://www.conventionalcommits.org/) (e.g. `feat:`, `fix:`, `docs:`, `chore:`).

## Code Quality

- Write clean and readable code.
- Keep functions small and focused.
- Prefer simple solutions over clever ones.

## Workflow

- Explain important changes before making them.
- Do not modify unrelated files.
